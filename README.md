# OpenScreen AI

OpenScreen AI — локальный AI-помощник для Python-разработчика на macOS. Первый MVP
отправляет текстовый вопрос в локальную Ollama и показывает ответ по мере генерации.
Экран, микрофон и данные пользователя в облачные сервисы не передаются.

## Требования

- macOS на Apple Silicon или Intel;
- Python 3.12 или новее;
- [Ollama](https://ollama.com/) и хотя бы одна загруженная языковая модель.

## Установка

Из каталога проекта выполните:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
cp .env.example .env
```

Файл `.env` локальный и игнорируется Git. В нём можно настроить адрес Ollama,
модель и таймаут запроса:

```dotenv
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5-coder:7b
OLLAMA_TIMEOUT_SECONDS=120
```

Укажите в `OLLAMA_MODEL` точное имя модели из вывода `ollama list`. Пример модели
в `.env.example` можно заменить на любую совместимую установленную модель.

## Запуск

Если Ollama ещё не запущена, откройте отдельный терминал и выполните:

```bash
ollama serve
```

Загрузите нужную модель (пример):

```bash
ollama pull qwen2.5-coder:7b
```

Затем в активированном виртуальном окружении запустите приложение:

```bash
python -m openscreen_ai.main
```

Либо после установки используйте команду `openscreen-ai`.

## Проверки

```bash
ruff check .
pytest
```

Тесты используют поддельный HTTP transport и не требуют запущенной Ollama.

## Текущий объём

MVP включает окно PySide6, текстовый ввод, потоковую генерацию через Ollama,
отмену запроса и обработку типовых сетевых ошибок. Захват экрана, аудио,
глобальные горячие клавиши и интеграция с AppKit запланированы на следующие этапы.
