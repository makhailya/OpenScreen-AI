# OpenScreen AI

Локальное приложение на Python и PySide6 для текстовых запросов к Ollama и голосового ввода. Диктовка вставляет распознанный текст в поле ввода. Проверьте текст и нажмите «Отправить», чтобы передать его модели.

## Установка и запуск

Для кандидата используется Python 3.12. Проверьте, что Ollama запущена локально и нужная модель уже доступна.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install .
cp -n .env.example .env
python -m openscreen_ai doctor
openscreen-ai
```

Укажите в `.env` имя установленной модели в `OLLAMA_MODEL`. По умолчанию адрес сервера — `http://127.0.0.1:11434`. `OLLAMA_TIMEOUT_SECONDS` задаёт таймаут запросов.

Для моделей с подтверждённой поддержкой отключения рассуждений установите в `.env` `OLLAMA_THINK=false`. Если модель выводит рассуждение обычным текстом без открывающего тега, приложение не может отличить его от ответа до появления закрывающего тега.

## Диктовка

Установите `python -m pip install '.[stt]'` в том же окружении. Задайте `OPENSCREEN_STT_MODEL_DIR` для совместимых файлов Parakeet и `OPENSCREEN_STT_VAD_MODEL_PATH` для Silero VAD. Формат файлов описан в [инструкции STT](docs/STT_PARAKEET_ULTRA.md). Команда `doctor` проверяет конфигурацию и доступность компонентов. Текстовый режим доступен без extra STT.

## Архитектура и тесты

Qt управляет окном и задачами в фоне. Аудиопоток проходит через Silero VAD и Parakeet. Ollama возвращает ответ частями по HTTP. Генерацию можно отменить. См. [архитектуру](docs/ARCHITECTURE.md).

```sh
python -m pip install '.[dev]'
python -m ruff check .
QT_QPA_PLATFORM=offscreen python -m pytest -ra
```

Автоматические проверки используют заглушки. Ручная приёмка микрофона, разрешений macOS, локальных моделей и реального Ollama для этого кандидата ожидается. Поддержка Intel и конкретных устройств требует проверки. Планы описаны в [дорожной карте](docs/ROADMAP.md).
