# План дальнейшей разработки

| Этап | Зависимости | Риски | Критерий готовности |
| --- | --- | --- | --- |
| 1. Floating overlay | PySide6 flags, геометрия окон macOS | Окно может терять фокус или перекрывать рабочую область | Панель закрепляется поверх окон, перемещается и остаётся читаемой на разных масштабах |
| 2. Глобальные горячие клавиши | Qt/macOS API или небольшая системная интеграция | Разрешения Accessibility и конфликт сочетаний | Пользователь может назначить и безопасно отключить сочетание |
| 3. Захват выбранного экрана/окна | ScreenCaptureKit или PyObjC, разрешение Screen Recording | Чувствительные данные и ограничения macOS | Захватывается только явно выбранная область; кадр виден пользователю до отправки локальной модели |
| 4. Мультимодальная модель | Ollama API с изображениями, подходящая vision-модель | Большое потребление памяти и неравномерная поддержка форматов | Один локальный снимок передаётся выбранной модели, а ошибки формата объясняются в UI |
| 5. Push-to-talk и faster-whisper | faster-whisper, микрофон, аудиозахват | Разрешение микрофона, задержка и расход памяти | Запись работает только при удержании команды, локальная транскрибация завершается и очищает временное аудио |
| 6. Swift/AppKit integration | Swift helper или PyObjC bridge | Межпроцессное взаимодействие и различия версий macOS | Python UI получает строго типизированные события macOS через документированный локальный интерфейс |
| 7. Настройки приватности и разрешений | Keychain при появлении секретов, системные диалоги разрешений | Неочевидные согласия и случайное сохранение данных | Пользователь управляет разрешениями и видит, какие данные обрабатываются и где |
| 8. Сборка `.app` для macOS | PyInstaller или Briefcase, подпись и notarization | Размер приложения, Qt plugins, Gatekeeper | Чистая сборка запускается на поддерживаемой macOS без установленного Python |
| 9. CI/CD и open-source релиз | GitHub Actions, лицензия, release workflow | Различия архитектур и утечка секретов в CI | Линтинг и тесты выполняются в CI, релиз содержит инструкции, лицензию и проверенные артефакты |

Этапы с доступом к экрану и микрофону требуют явного пользовательского выбора
и отдельного тестирования разрешений macOS. Пока эти функции не входят в MVP.
