# Готовность к запуску и безопасная диагностика

Документ описывает локальные предварительные требования и план будущей ручной проверки. Он
**не подтверждает готовность к production**. В рамках NIGHT-002 не проверялись
локальный адрес службы Ollama, установленная языковая модель, микрофон, разрешение
macOS TCC, запуск GUI и реальный инференс Parakeet/Silero. Их текущая
доступность неизвестна.

## Офлайн-команда doctor

Из корня проекта выполните:

```sh
python -m openscreen_ai doctor
```

Точка входа находится в src/openscreen_ai/__main__.py. Doctor не создаёт
QApplication, не запускает интерфейс, контроллер STT или нативную модель, не
открывает аудиоустройство, не отправляет HTTP-запросы и не соединяется с
Ollama. Он проверяет Python и обнаружение локальных зависимостей, валидирует
поддерживаемые настройки без вызова load_config()/load_dotenv() и проверяет,
можно ли читать настроенные файлы моделей. Команда читает .env только из
текущего каталога и только если сам путь указывает на обычный файл размером не
больше 1 МиБ; символьные ссылки, специальные файлы (включая FIFO) и большие
файлы отклоняются до чтения. Файл и переменные окружения процесса не изменяются.
В вывод не попадают значения, URL, пути, тексты исключений, имена моделей и
устройств.

Пример, когда .env и пути STT не настроены:

```text
PASS python: Python 3.13.7 supported
PASS config_file: not present; defaults and process settings apply
PASS core_dependencies: available
PASS qt: bindings available
PASS llm_config: valid syntax; endpoint availability not checked
WARN stt: optional speech recognition is not configured
```

Статус python включает безопасную версию интерпретатора в формате
major.minor.micro.
Категории и значения означают следующее:

| Категория | Значение |
|---|---|
| python | Базовое требование проекта: Python 3.12 или новее; версия выводится без пути к интерпретатору. |
| config_file | .env в текущем каталоге отсутствует или прочитан как обычный UTF-8-файл размером до 1 МиБ. |
| core_dependencies | Найдены обязательные модули httpx и dotenv. |
| qt | Найден PySide6.QtWidgets; это не доказывает, что интерфейс запустится. |
| llm_config | Проверен синтаксис URL, имени модели и таймаута; доступность адреса и наличие модели не проверяются. |
| stt | Не настроены или заданы не полностью необязательные пути STT; это предупреждение. |
| stt_python | Для настроенного STT проверяется поддерживаемый диапазон Python 3.12–3.13. |
| stt_model_paths | Настроенные пути Parakeet/VAD и ожидаемые файлы доступны для чтения; содержимое не проверяется. |
| stt_dependencies | Найдены необязательные модули sherpa_onnx, sounddevice и numpy; нативный код не загружается. |

Коды завершения стабильны для скриптов и CI: 0 — обязательные проверки
пройдены, предупреждения допустимы; 1 — хотя бы одна обязательная проверка
завершилась ошибкой; 2 — команда вызвана с неподдерживаемыми аргументами.
Например, неверная LLM-конфигурация даёт FAIL llm_config: invalid local
configuration и код 1, не раскрывая некорректное значение. Если не найден
обязательный пакет, doctor продолжает выводить безопасные статусы вместо
traceback; валидатор конфигурации может иметь статус WARN.

Doctor подтверждает только перечисленные локальные предварительные условия.
Валидная LLM-конфигурация не означает, что Ollama работает или модель установлена.
Читаемый файл модели может быть повреждён или несовместим. Необязательное
предупреждение STT не означает, что базовый текстовый режим недоступен.

## Требования и объявленные версии

В [README.md](../README.md) и [pyproject.toml](../pyproject.toml) заявлены
macOS на Apple Silicon или Intel и Python >=3.12. Обязательные пакеты:
httpx>=0.27,<1, PySide6-Essentials>=6.7,<7 и python-dotenv>=1.0,<2.
Дополнительная группа stt объявляет numpy>=1.26,<3,
sherpa-onnx==2.0.1 и sounddevice>=0.5,<1 для Python ниже 3.14. Проверка
доступности STT в исходном коде указывает, что Parakeet проверяется на Python
3.12 и 3.13; реальный запуск модели в этой миссии не выполнялся.

В dev объявлены pytest>=8,<9 и ruff>=0.8,<1. В NIGHT-002 Architect повторно
запустил полный fake-only набор: **169 passed** на Python 3.13.7 с pytest
9.1.1. Совместимость с pytest 8 остаётся **не подтверждена**: эта среда
использует pytest вне объявленного диапазона; Python 3.12.16 доступен, но в
нём отсутствуют pytest и зависимости проекта. Ruff и compileall прошли на
доступных окружениях. Проверки выполнялись без сети и реальных устройств и
не подтверждают запуск приложения, Ollama или моделей.

Команды установки и проверок ниже приведены в README; установку в этой миссии
не выполняли:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
cp .env.example .env
ruff check .
pytest
```

Дополнительная группа stt объявлена в pyproject.toml. Команда установки
python -m pip install -e '.[stt]' приведена в сообщении ошибки класса
SttDependencyError в src/openscreen_ai/stt/errors.py (это подсказка для
исправления ошибки STT, а не команда из модуля doctor). Установка не проверяет
содержимое моделей, доступ к PortAudio или разрешение macOS на микрофон. Не
устанавливайте пакеты в рамках автономной проверки.

## Переменные конфигурации и значения по умолчанию

load_config() из src/openscreen_ai/config.py использует эти настройки LLM.
Doctor проверяет тот же синтаксис, не вызывая эту функцию, которая загружает
.env в переменные окружения процесса. Значения окружения процесса имеют
приоритет над значениями из .env.

| Ключ | Значение по умолчанию/пример | Локальная проверка |
|---|---|---|
| OLLAMA_BASE_URL | Значение AppConfig, если настройка отсутствует: http://127.0.0.1:11434 | Полный URL http/https на localhost или loopback IP; логин и пароль в URL запрещены. |
| OLLAMA_MODEL | Значение AppConfig, если настройка отсутствует: qwen2.5-coder:7b | Непустое имя; doctor не проверяет наличие модели. |
| OLLAMA_TIMEOUT_SECONDS | 120 | Конечное число больше нуля. |
| OPENSCREEN_STT_MODEL_DIR | Не задано | Необязательный каталог с четырьмя файлами Parakeet ниже. |
| OPENSCREEN_STT_VAD_MODEL_PATH | Не задано | Необязательный путь к отдельной модели Silero VAD. |

Отдельно: в шаблоне [.env.example](../.env.example) задано
OLLAMA_MODEL=gemma4:e2b. Это значение шаблона, а не запасное значение AppConfig;
после копирования шаблона в .env оно станет явной настройкой приложения. README
также приводит пример qwen2.5-coder:7b. Ни один из примеров не подтверждает,
что соответствующая модель установлена локально.

По умолчанию пути STT не заданы; приложение может работать с ручным текстовым
вводом. SttConfig по умолчанию не выбирает конкретное аудиоустройство,
использует mono 16 kHz, четыре потока инференса, вычисления на CPU и текущие
настройки VAD. В main.py нет поддерживаемой переменной окружения для выбора
аудиоустройства.

В каталоге Parakeet нужны encoder.int8.onnx, decoder.int8.onnx,
joiner.int8.onnx и tokens.txt; OPENSCREEN_STT_VAD_MODEL_PATH указывает на
отдельный файл Silero VAD. Doctor проверяет доступность чтения, но не хеширует,
не загружает, не скачивает и не проверяет содержимое моделей. Не включайте
личные пути моделей и значения .env в общие логи и отчёты.

Для закреплённого Parakeet Ultra INT8 через тот же Sherpa-ONNX layout см.
[STT_PARAKEET_ULTRA.md](STT_PARAKEET_ULTRA.md). В STT-сессии VAD может выдать
несколько пронумерованных сегментов: штатный Stop останавливает capture,
обрабатывает уже поставленные в очередь аудиоблоки и завершает хвост VAD,
после чего UI собирает сегменты в индексном порядке в поле ввода. LLM запрос
начинается только после ручного нажатия «Отправить». Отмена/закрытие сбрасывают
частичный текст; потеря audio blocks,
пропущенный индекс, конфликтующий дубликат или превышение лимита завершают
диктовку безопасной ошибкой без отправки неполного текста. Fake-only тесты
этого поведения не подтверждают фактическую работу микрофона или полного GUI.

## Частые ошибки и безопасная проверка

| Симптом/категория | Что проверить локально |
|---|---|
| FAIL python | Используется интерпретатор ниже минимума Python 3.12. Настроенный STT поддерживается на Python 3.12–3.13. |
| FAIL core_dependencies или FAIL qt | Сверить окружение с зависимостями проекта; doctor ничего не устанавливает. |
| FAIL config_file | Приватно проверить .env: это обычный, не символьная ссылка, читаемый UTF-8-файл размером не больше 1 МиБ с корректным dotenv-синтаксисом. Doctor не раскрывает путь или строку ошибки. |
| FAIL llm_config | Приватно проверить loopback URL без учётных данных, непустое имя модели и конечный положительный timeout. |
| WARN stt | Необязательные пути STT настроены не полностью; базовая проверка может вернуть 0. |
| WARN stt_model_paths | Проверить четыре файла Parakeet и отдельный файл Silero; значения путей не выводятся. |
| WARN stt_dependencies или WARN stt_python | Необязательная подсистема STT не готова к реальному запуску; это не означает, что сломан текстовый режим. |
| Общая ошибка STT в интерфейсе | Локально проверить необязательные зависимости, пути и разрешение на микрофон. Интерфейс показывает общее безопасное сообщение, логи используют фиксированную категорию; внутренний сигнал контроллера может содержать текст исключения, поэтому не подключайте обработчик, который пишет этот текст в лог. |
| Нет ответа LLM при валидном llm_config | Doctor не проверяет доступность службы и модели. Подтверждать их можно только в отдельно разрешённой ручной сессии. |

## Идентичность запроса и безопасные события

Каждое принятое нажатие «Отправить» получает случайный идентификатор логического
запроса. Повторное нажатие, пока генерация активна, отклоняется и учитывается как
дубликат; тот же текст после завершения можно отправить отдельно, и он получит
новый идентификатор. Остановка диктовки сохраняет распознанный текст в поле ввода
и сама не запускает LLM.

Диагностические события используют фиксированные имена `llm.send_requested`,
`llm.request_created`, `llm.request_started`, `llm.http_attempt_started`,
`llm.http_attempt_finished`, `llm.request_cancel_requested`,
`llm.request_cancelled`, `llm.request_completed`, `llm.request_failed`,
`llm.callback_ignored_stale` и `llm.duplicate_send_blocked`. HTTP start фиксируется
в HTTPX request hook; каждая начатая попытка получает ровно одно событие finish с
исходом `success`, `provider_error`, `transport_error` или `cancelled`.

Снимок счётчиков содержит `send_actions_total`, `logical_requests_total`,
`http_attempts_total`, `completed_requests_total`, `cancelled_requests_total`,
`failed_requests_total`, `duplicate_send_blocked_total` и
`stale_callbacks_ignored_total`. Повторных попыток автоматически нет.
Диагностические записи содержат только фиксированную категорию события,
случайные ID, monotonic time/elapsed, состояние и исход; они не включают текст
запроса/ответа, HTTP-заголовки, токены, произвольные ошибки или значения адреса
Ollama. Это подтверждено fake-only проверками и не является проверкой реальной
Ollama, GUI или микрофона.

## Разрешение macOS на микрофон

Doctor не запрашивает и не проверяет разрешение macOS TCC. Во время NIGHT-002
разрешение не проверялось, поэтому его текущее состояние неизвестно. В будущей
явно разрешённой GUI-проверке оператор вручную открывает **System Settings
→ Privacy & Security → Microphone** и разрешает доступ только для одобренного
теста. Не автоматизируйте системный запрос и не меняйте настройки приватности.
Отказ в разрешении не даёт права повторять попытку. При отказе или неожиданном
устройстве остановите аудио-сценарий и отметьте его как BLOCKED.
