# Подготовка локального окружения OpenScreen-AI

Эта инструкция описывает будущую подготовку, но не является подтверждением установленной модели или работающего микрофона. DAY-001 не устанавливал зависимости, не менял пользовательский `.env`, не запускал Ollama, модели, GUI или аудиоустройства. Все команды установки ниже **только документированы и не выполнялись**.

## Что понадобится

- macOS на Apple Silicon или Intel; версия платформы должна быть подтверждена в отдельной ручной сессии.
- Python 3.12 или 3.13 для STT; `pyproject.toml` требует Python >=3.12, а `check_stt_available()` ограничивает проверенный STT runtime версиями 3.12–3.13.
- PySide6 Essentials, `httpx` и `python-dotenv` из обязательных project dependencies.
- Для тестов: pytest >=8,<9 и Ruff >=0.8,<1 из `.[dev]`.
- Для диктовки: `numpy`, `sherpa-onnx==2.0.1`, `sounddevice` из `.[stt]`.
- Ручно полученные локальные Parakeet и Silero VAD assets. Приложение их не загружает.
- Локально выбранная совместимая модель Ollama. Проверка списка моделей в этом документе не выполняется.

В INT-002B.1 Python 3.13.7 имел pytest 9.1.1 и базовые UI/HTTP зависимости, но не имел `numpy`, `sherpa-onnx` и `sounddevice`. Python 3.12.16 не имел pytest или project dependencies. Эти исторические сведения относятся к проверке 2026-11-11; перед запуском состояние надо проверить заново.

## Создание тестового окружения — только после отдельного согласования

Предпочтительный вариант на чистой локальной ветке:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev,stt]'
python --version
python -m pytest --version
ruff --version
```

Установка обращается к пакетным индексам и меняет виртуальное окружение; в DAY-001 её не выполняли. Python 3.13 допустим по коду для optional STT, но текущий исторический pytest 9.1.1 не входит в объявленный проектом диапазон pytest 8. Для воспроизводимого поддерживаемого прогона нужен Python 3.12 и pytest 8 в отдельно подготовленном окружении.

## Модельные файлы и пути

Каталог Parakeet должен содержать необходимые файлы, имена которых проверяет doctor:

```text
encoder.int8.onnx
decoder.int8.onnx
joiner.int8.onnx
tokens.txt
```

Подходящие каталоги Parakeet TDT v2 и закреплённого Ultra INT8 используют этот
же контракт имён; для переключения варианта меняется только значение
`OPENSCREEN_STT_MODEL_DIR`. См. [настройку Ultra и provenance](STT_PARAKEET_ULTRA.md).

Путь к отдельному файлу Silero VAD задаётся отдельно. После того как владелец выберет расположение и проверит происхождение/совместимость assets, параметры можно передать только процессу:

```sh
export OPENSCREEN_STT_MODEL_DIR='/local/private/path/to/parakeet'
export OPENSCREEN_STT_VAD_MODEL_PATH='/local/private/path/to/silero-vad.onnx'
```

Это примеры с placeholders; подставляйте фактические локальные пути только в приватном терминале. Не вставляйте значения в общий чат, issue, Git или отчёт. Doctor проверяет наличие и читаемость ожидаемых путей, но не подтверждает целостность, формат, совместимость или качество распознавания. При отсутствии любого asset оставьте STT не настроенным и не запускайте dictation.

### Выбор аудиоустройства

В текущем composition root нет поддерживаемой переменной окружения для выбора
аудиоустройства. `SttConfig.audio_device` остаётся `None`, то есть
`sounddevice` выбирает системное input-устройство. До отдельного разрешённого
ручного теста не менять это поведение. Capture ожидает mono float32, 16 kHz;
при стандартном 40 ms block очередь ограничена 20 блоками (800 ms), а новые
блоки при переполнении отбрасываются и учитываются в метриках. Stop кооперативен:
синхронный native decoder нельзя принудительно прервать из текущего worker.

## LLM настройки

`AppConfig` по умолчанию задаёт loopback URL `http://127.0.0.1:11434`, модель `qwen2.5-coder:7b` и timeout 120 секунд. `.env.example` задаёт `gemma4:e2b`; это пример, а не тот же default. Наличие этих строк не подтверждает, что tag присутствует в локальной библиотеке Ollama.

Перед отдельной разрешённой сессией владелец выбирает tag и проверяет его локально. Значения для процесса можно задать так:

```sh
export OLLAMA_BASE_URL='http://127.0.0.1:11434'
export OLLAMA_MODEL='your-local-model-tag'
export OLLAMA_TIMEOUT_SECONDS='120'
```

MVP разрешает только localhost/loopback адрес. Не помещайте логин, пароль или token в URL. Doctor не обращается к Ollama и не проверяет model tag; безопасная ошибка provider после DAY-001 сообщает проверить `OLLAMA_MODEL`, не раскрывая тело HTTP-ошибки.

## Проверка и запуск

Из корня checkout после установки и настройки, но до доступа к микрофону:

```sh
python -m openscreen_ai doctor
python -m pytest -q
ruff check .
```

Doctor должен завершиться без `FAIL`; `WARN stt` допустим для текстового режима, но диктовка будет скрыта, пока локальные prerequisites не пройдут проверку. Запуск текстового приложения — `python -m openscreen_ai.main` или установленная команда `openscreen-ai`. Эти команды не выполнялись в DAY-001.

Перед первым запросом вручную подтвердите loopback endpoint и выбранный model tag в собственной локальной сессии. Не считать `doctor` проверкой доступности сервиса или выполненного inference.

## macOS microphone permission

Первый реальный запуск диктовки требует осознанного пользовательского разрешения macOS TCC. Владелец должен выбрать правильное приложение/терминал в **System Settings → Privacy & Security → Microphone** и сам подтвердить доступ. DAY-001 не запускал GUI, не открывал device и не изменял TCC. Отказ в разрешении — BLOCKED для STT; не обходите отказ и не меняйте системные настройки автоматически.

## Наблюдение за ресурсами

Во время будущей авторизованной сессии записывайте только безопасные агрегаты: время запуска, время до первой части ответа, end-to-end latency, peak RSS, CPU, ошибки, queue depth/drops и stop duration. Не сохраняйте аудио, транскрипт, prompt, абсолютные пользовательские пути, env values или exception bodies в общий результат. На macOS RSS можно наблюдать через Activity Monitor или командой `ps -o rss= -p "$PID"` в локальном терминале после ручного запуска. Единицы `ps` и способ вычисления peak RSS указывайте в отчёте; разовое значение не является peak.

## Частые блокеры

| Статус/ошибка | Следующий безопасный шаг |
|---|---|
| Doctor: `WARN stt` | Оставить текстовый режим; согласовать Python/extra/assets перед live STT. |
| Не найдены пакеты `numpy`, `sherpa-onnx`, `sounddevice` | Показать владельцу предлагаемую команду установки и дождаться отдельного разрешения. |
| Не найдены Parakeet/VAD файлы | Владелец выбирает источник и локальное хранение; ничего автоматически не скачивать. |
| Ollama сообщает, что не нашла настроенную модель | Приватно сверить выбранный `OLLAMA_MODEL` с локальной моделью; не публиковать значение из личного окружения. |
| Ollama недоступна или превышен timeout | Проверить локальный сервис и loopback endpoint в отдельно разрешённой сессии. |
| Микрофон запрещён или устройство отсутствует | Завершить STT тест как BLOCKED и обратиться к владельцу macOS-сессии; не менять TCC автоматически. |
| В native decode зависает остановка | Остановить сценарий согласно плану live test; в DAY-001 не добавляется hard kill для внутрипроцессного decoder. |

## Откат

Переменные, заданные через `export`, исчезают после закрытия shell; используйте отдельную shell-сессию и не редактируйте существующий `.env` без отдельного разрешения. Не удаляйте модели, кэши, venv или результаты автоматически. Если в отдельной будущей задаче разрешено создать только выделенную venv, откатывайте только её и только после сверки точного пути. На момент подготовки DAY-001 кодовые изменения находятся в рабочем дереве `feature/integration-preparation` и ещё не закоммичены; публикации не было.
